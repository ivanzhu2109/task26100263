# task26100263

BehaviorLens 有序漏斗匹配库（Go）。

## API

- `Build(steps []string, window int64) Query`：构造查询，包含有序步骤与转换窗口（毫秒）。
- `Scan(query Query, next func() (Event, bool), emit func(userID string, path []Event)) []int`：
  从只能向前读取的 `next` 逐条取得事件，通过 `emit` 逐用户交付所选路径，
  返回每一步的累计到达用户数。

输入需已按用户 ID、时间戳、事件 ID 升序排列，同一用户事件连续。
路径规则：依次匹配前 m 步、可跳过无关事件、所选事件严格递增且不可复用；
末步与首步时间差不超过 window（取等有效，窗口从实际所选首步起算）。
每用户选一条路径：步数最多 → 首尾时间差最小 → (时间戳, 事件ID) 序列字典序最小。

## 运行

```sh
go build ./...   # 构建
go test ./...    # 运行全部测试（固定用例 + 随机穷举对照）
```

测试覆盖：窗口 10ms 下 A@0/A@9/B@10/C@18 须选出从 9 开始的完整路径、
窗口取等号边界、未命中首步不输出，以及 3000 组小规模随机事件
（含重复步骤、同一事件匹配多步、相同时间戳、最长路径耗时并列）
与穷举全部有效路径的独立参照对比路径与计数。
